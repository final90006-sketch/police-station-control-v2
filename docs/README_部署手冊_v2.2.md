## 🚀 安裝 SOP（首次使用，15 分鐘完成）

### 步驟 1：複製檔案
1. 把 `PoliceStation_v2.2_部署版.xlsx` 複製到派出所共用磁碟區
2. 建議路徑：`G:\派出所共用\管制系統\PoliceStation.xlsx`
3. **不要重新命名加註派出所名**（避免日後升級時對應困難）

### 步驟 2：填設定表（**這一步必做**）
1. 開檔 → 跳到「**設定表**」分頁
2. 填 **A 區 三層組織**（B16-B19）：
   - 警察局名稱（例：高雄市政府警察局）
   - 分局名稱（例：岡山分局）
   - 派出所名稱（例：五甲派出所）
   - 派出所英文名（例：WUJIA POLICE STATION）
3. 填 **B 區 員警名冊**（B24 起）：
   - 編號、姓名、職稱、是否在職、是否納入統計、排序、備註
   - 最多 60 名
4. 確認 **C 區 全所閾值**（B87-B93）：
   - 毒調率目標、新進案件閾值、老案閾值、案件容量警示、案件容量上限、毒調逾期天數、歷史保留月數
   - **預設值已符合多數派出所**，需要調整時改

### 步驟 3：設密碼
1. 設定表整表受密碼保護，**預設密碼為 `KD2026`**
2. 各派出所**應更換為自己的密碼**：
   - 審閱 → 取消保護工作表 → 輸入 `KD2026`
   - 重新保護工作表 → 設新密碼
3. **每張統計頁也受密碼保護**（管制總覽 / 全般刑案分析 / 刑案管制 / 毒品調驗 / 交通績效 / 績效統計 / 跨期間趨勢 / 歷史資料 / 系統檢核）
4. **資料輸入頁（案件資料庫 / 交通取締明細 / 毒調 / 發展中）** 已解鎖輸入欄，但計算欄受保護

### 步驟 4：驗證安裝
1. 跳到「**系統檢核**」分頁（頁 15）
2. 看「全表健康度」大字：
   - 紅燈 0 + 7 大類縮影紅燈都是 0 → ✓ 安裝完成
   - 若有紅燈 → 點 G 欄「→ 跳轉」依規則描述修

## 📅 月例行作業（5-10 分鐘 / 月）

### 每月月底（承辦人責任）
1. **抄寫歷史快照**：
   - 跳到「歷史資料」分頁
   - Row 6 紅底「🚨 本月尚未抄寫」是警示
   - **選 A7:N7 整列 → Ctrl+C → 到下方主表第一筆空白列 → Ctrl+Shift+V → 值 → Enter**
   - Row 6 應變綠底「✓ 本月已抄寫」
2. **維護設定表 F 區**（婦幼/協尋件數）：
   - 設定表 row 181-184，填本月件數
3. **看頁 15 系統檢核**確認全綠燈

### 案件登錄（員警責任）
- 跳到「案件資料庫」分頁
- 任一空白列直接 key 入（22 欄）
- **★ 雙軌欄位非常重要**：
  - 「發生管轄」 = 案件發生地是否本所轄區
  - 「查獲管轄」 = 破獲時是哪轄區員警破的
  - **不要相同！** 例如拘提他轄掃碼車手 → 發生=他轄 / 查獲=本轄
- 「績效類別」3 選項（毒品線上/酒駕線上/其他線上）僅線上查獲時填，**留空白系統會自動算入發生數**

### 毒調人口管制（偵查佐責任）
- 跳到「毒品調驗人口管制」分頁
- 主表 14 欄全部 input
- **v2.2 新加 J 欄「最後到驗日」**：每次到驗後填寫，公式自動算「距今天數」
- 距今 > 30 日 → 系統自動標記應聲請強採書（候選清單右側）

## ❓ 常見問題

### Q1: 開檔跳「我們發現部分內容有問題」
- 通常是 **Excel 修復警示**，按「是」即可
- 若是某個 sheet 的 CF 被移除，是 openpyxl 寫入時與 Excel 預期格式略差，通常**不影響功能**
- 若有疑慮，可從備份重新部署

### Q2: 忘記密碼了
- **預設 `KD2026`** — 若已改密碼又遺失，請聯絡部署人員
- 部署人員可重新從 `PoliceStation_v2.2_部署版.xlsx` 部署（保留資料的方式：開舊檔複製 Tbl 整段貼新檔）

### Q3: 公式顯示 `#DIV/0!` 或 `#N/A`
- 全部公式都已包 `IFERROR` 容錯，理論上不應出現
- 若出現：按 F9 重算；仍有則回報工程方確認

### Q4: 列印超過 1 頁
- 頁 3 / 4 / 11 / 2.5 設為 A4 直式 1 頁
- 若仍超頁：檢查列印機紙張規格、邊界、是否啟用「縮放至一頁」

### Q5: 案件容量上限 1000 列不夠
- 修改 設定表 C 區「案件容量上限」即可
- 但檔案會變大、效能會降低，建議定期歸檔到「歷史資料」

## 🔄 升級流程（從 v43 / v2.1 → v2.2）

1. **備份舊檔**：複製到 `_backup/PoliceStation_old_YYYYMMDD.xlsx`
2. **複製 v2.2 部署版** 到正式位置（覆寫舊檔）
3. **重新填設定表** A 區（組織）+ B 區（員警）— **僅 15 分鐘**
4. **複製貼上歷史資料**：
   - 開舊檔 → 「歷史資料」整段選取 → Ctrl+C
   - 開 v2.2 → 「歷史資料」row 11 起 → Ctrl+V（**貼上值**）
5. **複製貼上案件資料庫**：同上邏輯，貼到 row 15+
6. 跑「系統檢核」確認全綠燈
